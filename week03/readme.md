# 3주차 주제

## 1. 브루트포스

브루트포스는 가능한 모든 경우의 수를 하나씩 전부 시도해보는 공격 방법이다.

예를 들어 카이사르 암호에서 키가 1부터 25까지라면, 모든 키를 하나씩 넣어보면서 원문이 나오는지 확인한다.

## 2. 빈도 분석

빈도 분석은 암호문에 등장하는 문자나 단어의 빈도를 분석해서 원문을 추측하는 방법이다.

단순 치환 암호처럼 같은 글자가 항상 같은 글자로 바뀌는 암호는 빈도 분석에 취약하다.

## 3. 키 공간이 작다는 의미

키 공간이란 암호에서 사용할 수 있는 모든 키의 경우의 수를 의미한다.

키 공간이 작다는 것은 가능한 키의 개수가 적다는 뜻이다. 예를 들어 카이사르 암호는 알파벳을 몇 칸 밀지 정하는 방식이기 때문에 가능한 키가 25개 정도밖에 없다.

키 공간이 작으면 공격자가 모든 키를 하나씩 대입해보는 브루트포스 공격으로 쉽게 암호를 풀 수 있다.

따라서 안전한 암호를 만들기 위해서는 키 공간을 충분히 크게 만들어야 한다.
